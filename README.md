# badapple-sleep

1. python script converts bad apple into csv files representing bad apple as sleep data (awake, REM, core, and deep sleep stages)
2. Swift app lets you import those csv files into iOS HealthKit
3. I tried to get the XCUI test working to scroll between the days and screenshot each day to basically automate the whole thing, but it kept crashing,
not having data, and the AI agent struggled for a whole day. I ended up just putting the app onto my phone, overwriting all my sleep data, and manually screenshotting around 400 times.
